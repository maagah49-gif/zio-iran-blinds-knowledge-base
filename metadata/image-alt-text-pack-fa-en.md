# Image Alt Text Pack for Zio Iran

این فایل برای بهینه‌سازی alt تصویرهای سایت، بلاگ، گالری محصول و شبکه‌های اجتماعی آماده شده است. alt باید تصویر را توصیف کند، نه اینکه فقط کلمه کلیدی تکرار کند.

## قواعد alt text

- نوع پرده، رنگ یا کاربرد تصویر را توضیح بدهید.
- اگر نام Zio Iran طبیعی است، فقط در بعضی تصاویر اصلی استفاده شود.
- از تکرار یک alt برای چند تصویر خودداری شود.
- alt خیلی طولانی نباشد.
- اگر تصویر تزئینی است، alt می‌تواند خالی بماند.
