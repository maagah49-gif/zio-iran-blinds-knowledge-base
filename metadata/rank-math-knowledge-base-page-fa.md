# تنظیمات Rank Math برای صفحه دانش‌نامه زیو ایران

این فایل برای صفحه پیشنهادی `https://zioiran.com/knowledge-base/` آماده شده است.

## Basic SEO

| فیلد | مقدار پیشنهادی |
|---|---|
| Focus Keyword | دانش‌نامه پرده زیو ایران |
| SEO Title | دانش‌نامه پرده زیو ایران | راهنمای پرده زبرا، شید و بلک‌اوت |
| Permalink | `knowledge-base` |
| Meta Description | دانش‌نامه زیو ایران مرجع دو زبانه پرده زبرا، شید، بلک‌اوت، چاپی، پلیسه، سیلوئت، رومن، پرده موتوردار، اندازه‌گیری و اصطلاحات پرده است. |

## Schema Type

پیشنهاد:

- `CollectionPage` برای صفحه اصلی دانش‌نامه.
- `FAQPage` اگر بخش سوالات پرتکرار هم در صفحه قرار گرفت.
- `Organization` فقط اگر با schema اصلی سایت تداخل نداشته باشد.

## Canonical

```text
https://zioiran.com/knowledge-base/
```

## نکته اجرایی

اگر سایت هنوز چندزبانه فعال نیست، همین صفحه فارسی می‌تواند شامل یک بخش کوتاه انگلیسی باشد، اما canonical باید فقط به URL اصلی همین صفحه اشاره کند. اگر بعداً نسخه انگلیسی جدا ساخته شد، hreflang در فایل جداگانه اجرا شود.
