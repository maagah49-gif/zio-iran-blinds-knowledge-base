# برنامه انتشار حداقلی صفحه دانش‌نامه زیو ایران

## هدف

هدف این برنامه این است که صفحه دانش‌نامه زودتر روی سایت منتشر شود، حتی اگر هنوز همه URLهای داخلی، صفحات انگلیسی یا لینک‌های دسته‌بندی نهایی نشده باشند.

## نسخه پیشنهادی برای شروع

برای انتشار اولیه از این فایل استفاده شود:

`wordpress-ready/knowledge-base-page-no-internal-links-fa.md`

این نسخه لینک داخلی نمونه ندارد و فقط به مخزن GitHub رسمی پروژه اشاره می‌کند.

## مراحل اجرا

| مرحله | کار | توضیح |
|---|---|---|
| 1 | ساخت برگه در وردپرس | عنوان: دانش‌نامه پرده‌های مدرن زیو ایران |
| 2 | جایگذاری متن | متن فایل no-internal-links را وارد کنید |
| 3 | تنظیم slug | `curtain-blinds-knowledge-base` |
| 4 | تنظیم Rank Math | از فایل `metadata/rank-math-knowledge-base-page-fa.md` استفاده شود |
| 5 | افزودن FAQ | سوالات آخر صفحه حفظ شوند |
| 6 | افزودن لینک GitHub | لینک مخزن در بخش منبع تکمیلی قرار بگیرد |
| 7 | انتشار | بعد از بازبینی نگارشی منتشر شود |
| 8 | ثبت در Search Console | URL جدید inspect و request indexing شود |
| 9 | لینک‌دهی داخلی بعدی | بعد از مشخص شدن URL دسته‌ها، لینک‌ها اضافه شوند |
| 10 | ثبت گزارش | وضعیت در فایل پیگیری روزانه ثبت شود |

## دلیل این روش

اگر منتظر کامل شدن همه لینک‌های داخلی بمانیم، صفحه اصلی دانش‌نامه دیرتر منتشر می‌شود. نسخه حداقلی باعث می‌شود Google زودتر صفحه، نام Zio Iran، موضوعات اصلی پرده و ارتباط GitHub را ببیند.

## احتیاط‌ها

- از لینک نمونه یا URL فرضی استفاده نشود.
- متن تبلیغاتی شدید اضافه نشود.
- ادعای بهترین، اولین یا بزرگ‌ترین بودن نوشته نشود.
- بعد از انتشار، فقط یک URL canonical برای صفحه تنظیم شود.
