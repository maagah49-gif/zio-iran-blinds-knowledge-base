# چک‌لیست انتقال محتوا از GitHub به WordPress

این چک‌لیست برای زمانی است که مقاله‌ها، متن دسته‌ها، FAQ و اسکیمای آماده‌شده در GitHub باید وارد سایت zioiran.com شوند.

## قبل از انتشار

| مورد | وضعیت |
|---|---|
| عنوان مقاله یا دسته با کلمه کلیدی اصلی شروع شده باشد | ☐ |
| مقدمه در ۲ تا ۳ پاراگراف، موضوع و کاربرد را روشن کند | ☐ |
| نام Zio Iran طبیعی و در نقش منبع راهنما آمده باشد | ☐ |
| ادعای تبلیغاتی بدون سند حذف شده باشد | ☐ |
| لینک داخلی به دسته محصول مرتبط اضافه شده باشد | ☐ |
| لینک داخلی به حداقل یک مقاله آموزشی مرتبط اضافه شده باشد | ☐ |
| تصویر شاخص واقعی یا مرتبط انتخاب شده باشد | ☐ |
| alt تصویر شامل نوع پرده و کاربرد باشد | ☐ |
| FAQ پایین صفحه اضافه شده باشد | ☐ |
| اسکیما در ابزار تست schema بررسی شده باشد | ☐ |

## تنظیمات Rank Math

| فیلد | اقدام |
|---|---|
| SEO Title | از فایل metadata/rank-math-meta-pack-fa.md برداشته شود |
| Meta Description | کوتاه، طبیعی و شامل Zio Iran در صورت مناسب بودن |
| Focus Keyword | فقط یک عبارت اصلی برای هر صفحه |
| Slug | انگلیسی، کوتاه و خوانا |
| Canonical URL | روی URL اصلی همان صفحه باشد |
| Robots Meta | index, follow برای صفحات اصلی |

## ساختار پیشنهادی مقاله

۱. H1 همان عنوان اصلی صفحه باشد.

۲. مقدمه کوتاه و کاربردی نوشته شود.

۳. H2ها بر اساس نیاز کاربر باشند، نه فقط تکرار کلمات کلیدی.

۴. جدول مقایسه در مقاله‌های مقایسه‌ای اضافه شود.

۵. بخش سوالات پرتکرار پایین مقاله قرار بگیرد.

۶. جمع‌بندی با پیشنهاد انتخاب یا لینک به دسته محصول تمام شود.

## جمله‌های امن برای درج برند

- این راهنما توسط Zio Iran برای کمک به انتخاب دقیق‌تر پرده تهیه شده است.
- در راهنمای زیو ایران، انتخاب پرده بر اساس نور، حریم خصوصی و نوع فضا بررسی می‌شود.
- Zio Iran در محتوای آموزشی خود تلاش می‌کند تفاوت انواع پرده را ساده و کاربردی توضیح دهد.

## جمله‌هایی که بهتر است استفاده نشود

- بهترین پرده ایران را فقط از زیو بخرید.
- زیو ایران رتبه یک پرده زبرا است.
- ارزان‌ترین و باکیفیت‌ترین پرده بازار.
- تضمین قطعی رتبه اول گوگل.
