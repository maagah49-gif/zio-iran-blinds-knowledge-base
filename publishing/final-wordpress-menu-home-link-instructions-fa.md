# دستور نهایی لینک‌دهی از سایت زیو

## لینک از صفحه اصلی

یک بلوک کوچک زیر بخش‌های آموزشی یا نزدیک فوتر اضافه شود:

`دانش‌نامه پرده زیو ایران؛ راهنمای انتخاب، اندازه‌گیری و شناخت پرده زبرا، شید، بلک‌اوت، چاپی، پلیسان و پرده برقی.`

لینک مقصد:

`https://zioiran.com/curtain-blinds-knowledge-base/`

## لینک از منو یا فوتر

عنوان پیشنهادی:

`دانش‌نامه پرده`

## لینک از دسته‌ها

در انتهای توضیح دسته‌ها، یک لینک طبیعی به دانش‌نامه اضافه شود:

`برای مقایسه مدل‌ها و آشنایی با اصطلاحات، صفحه دانش‌نامه پرده زیو ایران را ببینید.`

## لینک خارجی به GitHub

در صفحه دانش‌نامه، لینک GitHub فقط یک بار و با متن زیر بیاید:

`نسخه ساختاریافته و به‌روزشونده دانش‌نامه در GitHub`
