# چک‌لیست اجرای صفحه دانش‌نامه در وردپرس

این چک‌لیست برای ساخت صفحه `https://zioiran.com/knowledge-base/` در وردپرس زیو ایران استفاده می‌شود.

## قبل از ساخت صفحه

| کار | وضعیت |
|---|---|
| انتخاب URL نهایی `/knowledge-base/` | آماده |
| آماده بودن متن فارسی صفحه | آماده |
| آماده بودن HTML صفحه | آماده |
| آماده بودن Meta Title و Meta Description | آماده |
| آماده بودن FAQ schema | آماده |
| آماده بودن CollectionPage schema | آماده |
| بررسی URL واقعی دسته‌بندی‌ها | نیازمند اجرا در سایت |

## بعد از انتشار

1. صفحه را در دسکتاپ بررسی کنید.
2. صفحه را در موبایل بررسی کنید.
3. لینک GitHub را تست کنید.
4. schema را در ابزار تست اسکیما بررسی کنید.
5. URL صفحه را در Search Console Inspect کنید.
6. Request Indexing بزنید.
7. URL منتشرشده را در فایل tracking ثبت کنید.
8. از صفحه درباره ما یا فوتر به این صفحه لینک بدهید.

## خطاهای رایج

- استفاده از URL نمونه دسته‌بندی بدون اصلاح.
- قرار دادن فقط لینک فوتر و نداشتن لینک داخل متن.
- تکرار بیش از حد نام زیو ایران در متن.
- استفاده هم‌زمان از چند schema مشابه Organization در یک صفحه بدون هماهنگی.
- فراموش کردن canonical.
