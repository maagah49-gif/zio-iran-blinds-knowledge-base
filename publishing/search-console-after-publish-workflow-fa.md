# Workflow بعد از انتشار در Search Console

این فایل برای بعد از انتشار هر مقاله یا آپدیت صفحه در zioiran.com آماده شده است.

## مراحل فوری بعد از انتشار

| مرحله | اقدام | هدف |
|---|---|---|
| ۱ | URL را در مرورگر باز کنید | بررسی 200 بودن صفحه |
| ۲ | عنوان و متا را در سورس یا Rank Math چک کنید | مطمئن شدن از نمایش درست |
| ۳ | لینک‌های داخلی را تست کنید | جلوگیری از 404 و مسیر اشتباه |
| ۴ | صفحه را در موبایل ببینید | خوانایی و چیدمان |
| ۵ | URL Inspection در Search Console | درخواست ایندکس |
| ۶ | Rich Results Test | بررسی FAQ/Product/HowTo schema |
| ۷ | ثبت در گزارش هفتگی | پیگیری نتیجه |

## اولویت ثبت URLها

۱. صفحات دسته محصول پول‌ساز

۲. مقالات پشتیبان همان دسته‌ها

۳. صفحه درباره زیو ایران

۴. فایل یا صفحه llms.txt / AI Search guide

۵. صفحه FAQ کلی

## بعد از ۷ روز

| داده | اقدام |
|---|---|
| Query با impression اما کلیک کم | بهبود Title و Meta Description |
| Position بین ۸ تا ۲۰ | تقویت لینک داخلی و FAQ |
| صفحه بدون impression | بررسی index، canonical، sitemap و کیفیت محتوا |
| CTR پایین | بازنویسی عنوان و توضیحات |
| کلمات غیرمرتبط | اصلاح تیترها و متن |

## بعد از ۳۰ روز

- صفحه‌هایی که ورودی گرفته‌اند، با جدول، FAQ و تصویر بهتر تقویت شوند.
- صفحه‌هایی که impression دارند ولی کلیک نمی‌گیرند، متای جدید بگیرند.
- صفحه‌هایی که هیچ داده‌ای ندارند، از نظر index و لینک داخلی بررسی شوند.
- صفحات دسته زبرا، شید، بلک‌اوت و چاپی دوباره اولویت‌گذاری شوند.

## نکته مهم

ثبت URL در Search Console تضمین رتبه نیست، اما کمک می‌کند گوگل سریع‌تر صفحه را ببیند. ارزش اصلی از کیفیت محتوا، لینک داخلی، سرعت صفحه، تجربه موبایل و ارتباط صفحه با نیاز کاربر می‌آید.
