# نقشه URL صفحه دانش‌نامه فارسی و انگلیسی

## هدف

این فایل URLهای پیشنهادی، فایل‌های منبع و دارایی‌های مرتبط با صفحه دانش‌نامه زیو ایران را یک‌جا نگه می‌دارد تا هنگام انتشار، لینک‌ها و schema با هم ناسازگار نشوند.

## نقشه اصلی

| بخش | فارسی | انگلیسی |
|---|---|---|
| URL پیشنهادی | `https://zioiran.com/curtain-blinds-knowledge-base/` | `https://zioiran.com/en/modern-blinds-knowledge-base/` |
| فایل متن کامل | `wordpress-ready/knowledge-base-page-wordpress-fa.md` | `wordpress-ready-en/knowledge-base-page-wordpress-en.md` |
| فایل انتشار سریع | `wordpress-ready/knowledge-base-page-no-internal-links-fa.md` | `wordpress-ready-en/knowledge-base-page-no-internal-links-en.md` |
| متادیتا | `metadata/rank-math-knowledge-base-page-fa.md` | `metadata/rank-math-knowledge-base-page-en.md` |
| schema | `schema/knowledge-base-page-schema-zioiran.json` | `schema/knowledge-base-page-schema-zioiran-en.json` |
| FAQ schema | `schema/knowledge-base-faq-schema-zioiran.json` | بعد از ساخت FAQ انگلیسی مستقل تکمیل شود |
| hreflang | `technical-seo/knowledge-base-hreflang-fa-en.md` | `technical-seo/knowledge-base-hreflang-fa-en.md` |

## جایگاه‌های پیشنهادی لینک‌دهی داخلی بعد از انتشار

| صفحه سایت | anchor پیشنهادی |
|---|---|
| صفحه اصلی | دانش‌نامه پرده‌های مدرن زیو ایران |
| پرده زبرا | راهنمای پرده زبرا در دانش‌نامه زیو |
| پرده شید | مقایسه شید و زبرا |
| پرده بلک‌اوت | راهنمای کنترل نور و بلک‌اوت |
| پرده چاپی | راهنمای آماده‌سازی پرده چاپی |
| پرده پلیسان | راهنمای پرده پلیسان |
| پرده سیلوئت | راهنمای پرده سیلوئت |
| پرده برقی | راهنمای پرده برقی و هوشمند |

## قاعده به‌روزرسانی

هر بار URL واقعی یکی از صفحات دسته‌بندی مشخص شد، همین فایل باید قبل از تغییر schema یا متن وردپرس به‌روزرسانی شود.
