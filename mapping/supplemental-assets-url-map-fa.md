# نقشه URL دارایی‌های مکمل

| دارایی | مسیر GitHub | کاربرد در سایت زیو ایران |
| --- | --- | --- |
| مقاله‌های فارسی مکمل | `articles/supplemental-fa/` | تبدیل به پست وبلاگ و لینک‌دهی داخلی |
| مقاله‌های انگلیسی مکمل | `articles/supplemental-en/` | نسخه انگلیسی GitHub Pages و محتوای bilingual |
| FAQهای فارسی | `faq/supplemental/` | استفاده در صفحه دانش‌نامه و Rank Math FAQ |
| Schemaهای مکمل | `schema/supplemental/` | استفاده کنترل‌شده در صفحه‌های وردپرس |
| بلوک‌های وردپرس | `wordpress-ready/supplemental/` | کپی در Gutenberg/HTML سفارشی |
| صفحه عمومی مکمل | `docs/supplemental-assets.html` | لینک‌دهی از README، سایت و Search Console |
| JSON ایندکس مکمل | `docs/supplemental-assets.json` | استفاده برای automation و AI search |

## نکته

قبل از استفاده از URLهای دسته‌بندی، مسیر واقعی دسته‌ها در zioiran.com باید با نقشه لینک‌دهی داخلی موجود تطبیق داده شود.
