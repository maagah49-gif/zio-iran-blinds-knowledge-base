# نقشه جایگزینی URLهای دسته‌بندی در صفحه دانش‌نامه

در فایل HTML صفحه دانش‌نامه، چند URL نمونه برای دسته‌بندی‌ها گذاشته شده است. قبل از انتشار روی سایت، باید این URLها با آدرس واقعی صفحات زیو ایران جایگزین شوند.

## URLهای نمونه فعلی

| محصول | URL نمونه داخل HTML | اقدام لازم |
|---|---|---|
| پرده زبرا | `/product-category/zebra/` | جایگزینی با URL واقعی صفحه پرده زبرا |
| پرده شید | `/product-category/roller-shades/` | جایگزینی با URL واقعی صفحه پرده شید |
| پرده بلک‌اوت | `/product-category/blackout/` | جایگزینی با URL واقعی صفحه بلک‌اوت |
| پرده چاپی | `/product-category/printed-blinds/` | جایگزینی با URL واقعی صفحه پرده چاپی |
| پرده پلیسه | `/product-category/pleated-blinds/` | جایگزینی با URL واقعی صفحه پرده پلیسه/پلیسان |
| پرده موتوردار | `/product-category/motorized-blinds/` | جایگزینی با URL واقعی صفحه پرده برقی/هوشمند |

## قانون لینک داخلی

- اگر صفحه دسته‌بندی اصلی وجود دارد، به همان صفحه لینک شود.
- اگر فقط محصول شاخص وجود دارد، فعلاً به محصول شاخص لینک شود و بعداً با صفحه دسته‌بندی جایگزین شود.
- اگر صفحه هنوز آماده نیست، لینک موقت گذاشته نشود.
- anchor text باید نام طبیعی محصول باشد، مثل `پرده زبرا` یا `پرده شید`.
