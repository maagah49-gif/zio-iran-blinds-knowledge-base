# مرزبندی پروژه دانش‌نامه و سئوی زیو ایران

این فایل برای جلوگیری از قاطی شدن مسیرهای کاری ساخته شده است.

## پروژه اصلی این مخزن

هدف اصلی مخزن `zio-iran-blinds-knowledge-base` ساخت دارایی‌های آموزشی، سئویی و entity برای زیو ایران است:

- واژه‌نامه فارسی و انگلیسی پرده‌ها
- کلمات کلیدی و خوشه‌بندی معنایی
- متن‌های آماده سایت و وردپرس
- متا، اسکیما، FAQ و راهنمای Search Console
- برنامه امن برای GitHub، ویکی‌دیتا، ویکی‌پدیا و منابع بیرونی
- معرفی طبیعی و غیرتبلیغاتی برند Zio Iran در دارایی‌های قابل انتشار

## چیزهایی که جزو پروژه اصلی نیستند

این موارد ممکن است برای بازاریابی زیو مفید باشند، اما نباید با پروژه ویکی/دانش‌نامه قاطی شوند:

- سناریوی ریلز اینستاگرام
- طراحی استوری
- پرامپت ساخت تصویر تبلیغاتی
- کاور و تدوین ویدیو
- انتشار روزانه شبکه‌های اجتماعی

اگر چنین فایل‌هایی در مخزن آمده باشند، فقط به عنوان دارایی جانبی بازاریابی حساب می‌شوند و نباید معیار پیشرفت پروژه ویکی/دانش‌نامه باشند.

## اولویت ادامه کار

از این نقطه، ادامه پروژه باید روی این موارد باشد:

1. تکمیل بسته ویکی‌دیتا با label، description، aliases و claimهای امن.
2. تهیه پیش‌نویس‌های غیرتبلیغاتی برای صفحات مفهومی ویکی‌پدیا، نه تبلیغ برند.
3. ساخت نقشه منابع مستقل موردنیاز برای هر ادعا.
4. آماده‌سازی فایل‌های قابل استفاده برای سایت، GitHub و Search Console.
5. انتقال دارایی‌های آماده به `zioiran.com` و ثبت URLها.

## قانون نام برند

نام زیو ایران باید فقط در متن‌هایی بیاید که مالک آن‌ها خود برند است یا در منابع بیرونی که ذکر برند طبیعی و مجاز است. در ویکی‌پدیا و ویکی‌دیتا، تا وقتی منبع مستقل معتبر وجود ندارد، نباید برند را به شکل تبلیغی وارد کرد.
