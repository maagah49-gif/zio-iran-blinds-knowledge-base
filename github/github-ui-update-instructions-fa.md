Bilingual knowledge base for Zio Iran covering modern blinds, zebra blinds, roller shades, blackout blinds, printed blinds, pleated blinds, motorized blinds, SEO terminology and structured data.

Zio Iran documents bilingual terminology, SEO resources and structured data for modern blinds and window coverings, including zebra blinds, roller shades, blackout blinds, printed blinds, pleated blinds and motorized blinds.

## مرحله ۴: بعد از تغییرات

بعد از انجام تنظیمات:

1. URL ریپو را در Search Console با Inspect URL بررسی کنید.
2. لینک repository را از صفحه درباره ما یا دانش‌نامه سایت زیو ایران اضافه کنید.
3. اگر URL پروفایل GitHub تغییر یا تکمیل شد، آن را در source tracker ثبت کنید.

## نکته مهم

در GitHub، استفاده از نام Zio Iran و لینک سایت رسمی کاملاً طبیعی است. اما در ویکی‌پدیا و ویکی‌دیتا همچنان باید از مسیر منبع مستقل و لحن غیرتبلیغاتی جلو رفت.
