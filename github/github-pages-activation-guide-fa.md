# راهنمای فعال‌سازی GitHub Pages برای دانش‌نامه زیو ایران

## هدف

با فعال‌سازی GitHub Pages، مخزن دانش‌نامه زیو ایران علاوه بر صفحه GitHub، یک صفحه HTML عمومی هم خواهد داشت. این کار برای نمایش بهتر، اشتراک‌گذاری راحت‌تر و اتصال شفاف‌تر سایت zioiran.com به دانش‌نامه مفید است.

## URL پیشنهادی بعد از فعال‌سازی

`https://maagah49-gif.github.io/zio-iran-blinds-knowledge-base/`

## مراحل فعال‌سازی در GitHub

1. وارد مخزن شوید:

`https://github.com/maagah49-gif/zio-iran-blinds-knowledge-base`

2. از بالای صفحه روی Settings بزنید.
3. از منوی کناری Pages را باز کنید.
4. در بخش Build and deployment، Source را روی Deploy from a branch بگذارید.
5. Branch را روی `main` قرار دهید.
6. Folder را روی `/docs` قرار دهید.
7. Save را بزنید.
8. چند دقیقه صبر کنید تا آدرس Pages فعال شود.

## بعد از فعال‌سازی

- آدرس GitHub Pages را باز کنید.
- لینک سایت zioiran.com را تست کنید.
- لینک مخزن GitHub را تست کنید.
- آدرس Pages را در فایل‌های لینک‌دهی و Search Console tracking ثبت کنید.

## نکته سئو

این صفحه جای سایت اصلی را نمی‌گیرد. نقش آن پشتیبانی از دانش‌نامه، citation، یکسان‌سازی entity و اتصال برند Zio Iran به موضوعات پرده‌های مدرن است.
