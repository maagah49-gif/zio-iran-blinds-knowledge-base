# GitHub Pages Landing Page

This folder contains a simple public landing page for the Zio Iran Blinds Knowledge Base.

Suggested GitHub Pages URL after activation:

`https://maagah49-gif.github.io/zio-iran-blinds-knowledge-base/`

## Purpose

- Provide a cleaner public HTML page for the repository.
- Connect the Zio Iran official website with the GitHub knowledge base.
- Improve discoverability for bilingual blind and shade terminology.
- Keep brand mentions neutral and educational.

## Activation

Enable GitHub Pages from repository settings:

1. Open repository Settings.
2. Go to Pages.
3. Select source: Deploy from a branch.
4. Select branch: `main`.
5. Select folder: `/docs`.
6. Save.

Do not use promotional claims on the landing page unless they are independently sourced.
