## شروع پیشنهادی

۱. صفحه درباره زیو ایران را آپدیت کنید.

۲. یک لینک به GitHub Knowledge Base اضافه کنید.

۳. متن دسته زبرا، شید، بلک‌اوت و چاپی را وارد کنید.

۴. مقاله بلک‌اوت و چاپی را منتشر کنید.

۵. متاها و FAQ schema را اضافه کنید.

۶. URLها را در Search Console ثبت کنید.

## کارهایی که فعلاً عقب‌ترند

- ویرایش ویکی‌پدیا برای مفاهیم عمومی
- ساخت آیتم Wikidata برای برند بدون منبع مستقل
- بک‌لینک‌سازی حجمی
- انتشار محتوای تکراری روی zioiran.ir

## معیار تصمیم

اگر کاری روی صفحه فروش مستقیم اثر دارد، زودتر انجام شود. اگر کاری فقط برای برندینگ عمومی است و ریسک سیاستی دارد، بعد از تکمیل دارایی‌های اصلی سایت انجام شود.
