# برنامه اجرای روز اول روی zioiran.com

این برنامه برای اولین روز اجرای عملی دارایی‌های GitHub روی سایت زیو ایران نوشته شده است. هدف این است که به جای پراکنده‌کاری، اول صفحات پول‌ساز و قابل اندازه‌گیری آپدیت شوند.

## هدف روز اول

اتصال مخزن GitHub به سایت اصلی، تقویت صفحه درباره ما، و آماده‌سازی چهار صفحه دسته اصلی برای سئو.

## ترتیب اجرای پیشنهادی

۱. اول صفحه درباره زیو ایران آپدیت شود، چون برای entity برند مهم است.

۲. بعد لینک GitHub اضافه شود تا رابطه رسمی دامنه و مخزن برقرار شود.

۳. سپس صفحات دسته زبرا، شید، بلک‌اوت و چاپی آپدیت شوند.

۴. در پایان، Search Console و تست schema انجام شود.

## معیار پایان روز اول

- صفحه درباره ما منتشر یا آپدیت شده باشد.
- حداقل یک لینک از zioiran.com به GitHub وجود داشته باشد.
- چهار صفحه دسته اصلی متن معرفی و متای بهتر داشته باشند.
- URLها در Search Console ثبت شده باشند.
- تغییرات در گزارش هفتگی ثبت شده باشد.
