- کلمات کلیدی اصلی و معادل‌های انگلیسی دسته‌بندی شده‌اند.
- مقاله‌ها و بلاگ‌درفت‌های فارسی و انگلیسی برای محصولات اصلی ساخته شده‌اند.
- متن آماده وردپرس برای دسته‌های فارسی اصلی و تکمیلی آماده است.
- متن آماده وردپرس انگلیسی برای هشت دسته اصلی آماده است.

- FAQ schema فارسی و انگلیسی برای دسته‌ها آماده شده است.
- راهنمای canonical و hreflang برای نسخه دو‌زبانه ساخته شده است.
- برنامه انتشار خارجی و ذکر امن برند آماده شده است.
- چک‌لیست انتقال وردپرس و کنترل کیفیت محتوا آماده شده است.

## وضعیت استفاده از نام برند

در متن‌ها نام زیو ایران / Zio Iran به شکل طبیعی و آموزشی آمده است. از ادعاهای پرریسک و تبلیغاتی مانند بهترین، بزرگ‌ترین، شماره یک یا مرجع رسمی بدون منبع پرهیز شده است. این رویکرد برای GitHub، پروفایل‌های خارجی، AI Search و حتی صفحات سایت امن‌تر است.

## وضعیت ویکی‌پدیا و ویکی‌دیتا

ویرایش مستقیم ویکی‌پدیا یا ویکی‌دیتا انجام نشده است. با توجه به محدودیت کپچا و حساسیت ضدتبلیغاتی این پلتفرم‌ها، فعلاً فقط فایل‌های راهنما، برچسب‌ها و توضیح‌های امن آماده شده‌اند. اقدام مستقیم فقط وقتی مناسب است که منبع مستقل معتبر برای برند یا کارخانه وجود داشته باشد.

## اولویت بعدی

1. انتقال چهار صفحه فارسی اصلی به وردپرس: زبرا، شید، بلک‌اوت، چاپی.
2. افزودن متا و FAQ schema همان صفحات.
3. ثبت URLها در Search Console.
4. لینک‌دهی داخلی از صفحه اصلی، بلاگ و دسته‌های مرتبط.
5. انتشار یک پست شبکه اجتماعی برای هر صفحه جدید.
6. بعد از ایندکس اولیه، ساخت نسخه انگلیسی در `/en/`.

## ریسک‌ها

- اگر متن‌ها فقط در GitHub بمانند و از سایت لینک نگیرند، اثر مستقیم روی فروش و رتبه سایت محدود می‌شود.
- اگر در ویکی‌پدیا/ویکی‌دیتا متن تبلیغاتی وارد شود، احتمال حذف و محدودیت حساب وجود دارد.
- اگر صفحات انگلیسی بدون hreflang و canonical درست ساخته شوند، ممکن است سیگنال‌های زبانی گوگل قاطی شود.
