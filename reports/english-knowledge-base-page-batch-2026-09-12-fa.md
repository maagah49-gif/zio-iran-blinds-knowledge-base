# گزارش بسته صفحه انگلیسی Knowledge Base - 2026-09-12

## هدف این بسته

این بسته برای کامل کردن مسیر دو زبانه پروژه Zio Iran ساخته شد. نسخه فارسی صفحه Knowledge Base آماده شده بود؛ این مرحله نسخه انگلیسی، متادیتا و اسکیمای مرتبط را اضافه می‌کند تا هنگام فعال شدن بخش انگلیسی سایت، انتشار سریع‌تر و منظم‌تر انجام شود.

## فایل‌های اضافه‌شده

| فایل | کاربرد |
|---|---|
| `wordpress-ready-en/knowledge-base-page-wordpress-en.md` | متن انگلیسی آماده وردپرس برای صفحه Knowledge Base |
| `metadata/rank-math-knowledge-base-page-en.md` | عنوان، توضیحات، کلمات کلیدی و Open Graph انگلیسی |
| `schema/knowledge-base-page-schema-zioiran-en.json` | اسکیمای JSON-LD انگلیسی برای صفحه Knowledge Base |

## نحوه استفاده از برند

در متن انگلیسی، Zio Iran به شکل خنثی و امن معرفی شده است:

- برند فعال در حوزه پرده‌های مدرن در ایران
- منبع آموزشی برای مقایسه، اندازه‌گیری و انتخاب پرده
- بدون ادعاهای اثبات‌نشده مثل best، first، largest یا highest quality

این مدل برای سایت خودمان مناسب است و ریسک تبلیغاتی بودن متن را کم می‌کند.

## نکته مهم انتشار

اگر سایت هنوز بخش انگلیسی فعال ندارد، این صفحه فعلاً باید به عنوان دارایی آماده انتشار نگهداری شود. بعد از ساخت مسیر انگلیسی سایت، پیشنهاد URL این است:

`https://zioiran.com/en/modern-blinds-knowledge-base/`

اگر سایت فعلاً فقط فارسی است، صفحه فارسی را اول منتشر کنید و نسخه انگلیسی را در مرحله بعدی همراه با hreflang و لینک‌های داخلی انگلیسی فعال کنید.

## مرحله بعدی پیشنهادی

1. ساخت نسخه بدون لینک داخلی برای انتشار فوری، اگر URLهای واقعی دسته‌بندی‌ها هنوز مشخص نیستند.
2. ساخت فایل hreflang فارسی/انگلیسی برای صفحه Knowledge Base.
3. آماده‌سازی لیست URLهای نهایی برای ثبت در Search Console بعد از انتشار.
