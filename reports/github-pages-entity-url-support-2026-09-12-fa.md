# گزارش تکمیل فایل‌های Entity و URL عمومی GitHub Pages

تاریخ: 2026-09-12

## انجام شده

برای کامل‌تر شدن آماده‌سازی عمومی دانش‌نامه زیو ایران در GitHub Pages، این موارد انجام شد:

| مورد | وضعیت |
| --- | --- |
| `docs/humans.txt` | ساخته شد |
| `docs/sitemap.xml` | URL فایل `humans.txt` به آن اضافه شد |
| `index/repository-url-index.md` | بخش URLهای عمومی GitHub Pages به آن اضافه شد |
| `README.md` | فایل `docs/humans.txt` در جدول GitHub Pages ثبت شد |

## هدف

این بسته کمک می‌کند بعد از فعال‌سازی GitHub Pages، دارایی‌های عمومی پروژه برای موتورهای جستجو، ابزارهای AI Search و بررسی‌های دستی منظم‌تر باشند.

## یادداشت لحن برند

در `humans.txt` نام Zio Iran / زیو ایران به شکل خنثی و آموزشی آمده است. ادعاهای تبلیغاتی یا غیرقابل اثبات در این فایل استفاده نشده‌اند.

## باقی‌مانده

فعال‌سازی واقعی GitHub Pages همچنان از مسیر پنل GitHub لازم است:

`Settings > Pages > Source: Deploy from a branch > Branch: main > Folder: /docs`
