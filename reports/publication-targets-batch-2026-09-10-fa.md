1. تکمیل GitHub repository description و topics.
2. تکمیل GitHub profile با معرفی کوتاه Zio Iran.
3. لینک دادن از سایت zioiran.com به knowledge base.
4. ثبت چند پروفایل بیرونی فارسی با متن کوتاه و یکدست.
5. پیگیری مقاله آموزشی مستقل درباره پرده مدرن، نه رپورتاژ تبلیغاتی.
6. ثبت همه URLها در source tracker.
