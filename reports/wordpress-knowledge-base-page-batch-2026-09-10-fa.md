| فایل | کاربرد |
|---|---|
| `wordpress-ready/knowledge-base-page-wordpress-fa.md` | متن کامل آماده برای ساخت صفحه دانش‌نامه در وردپرس |

## دلیل اهمیت

این صفحه سایت رسمی را به دانش‌نامه GitHub وصل می‌کند. از نظر سئو، این کار کمک می‌کند ارتباط بین `Zio Iran`، `زیو ایران`، `zioiran.com`، GitHub repository و کلمات کلیدی پرده‌های مدرن واضح‌تر شود.

## کارهای بعد از انتشار

1. بررسی نمایش صفحه در موبایل و دسکتاپ.
2. بررسی لینک GitHub داخل صفحه.
3. افزودن schema و تست آن در Rich Results یا Schema Validator.
4. ثبت URL صفحه در Search Console.
5. لینک دادن از صفحه درباره ما، فوتر یا صفحات دسته‌بندی به صفحه دانش‌نامه.

## وضعیت ویکی‌پدیا و ویکی‌دیتا

این مرحله هنوز انتشار مستقیم در ویکی‌پدیا یا ویکی‌دیتا نیست. این صفحه یک دارایی رسمی و مالکیتی است که بعداً می‌تواند به یکدست شدن entity برند و پیدا شدن منابع مرتبط کمک کند.
