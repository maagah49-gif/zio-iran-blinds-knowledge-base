# گزارش بسته لینک‌دهی سایت به GitHub - 2026-09-10

این مرحله برای اتصال مستقیم و طبیعی سایت رسمی زیو ایران به دانش‌نامه GitHub انجام شد. هدف، تقویت ارتباط بین `zioiran.com`، نام برند `Zio Iran / زیو ایران` و کلمات کلیدی پرده‌های مدرن است.

| فایل | کاربرد |

## نقطه شروع پیشنهادی

اولین اجرا بهتر است از یکی از این دو مسیر شروع شود:

1. ساخت صفحه مستقل `/knowledge-base/` در سایت زیو ایران.
2. افزودن یک بلوک کوتاه در صفحه درباره ما با لینک به GitHub knowledge base.

## اثر سئویی مورد انتظار

- سایت رسمی، GitHub و entity برند به هم وصل می‌شوند.
- کلمات فارسی مثل پرده زبرا، پرده شید، پرده بلک‌اوت و پرده چاپی به معادل‌های انگلیسی مثل zebra blinds، roller shades و blackout blinds نزدیک‌تر می‌شوند.
- GitHub repository از سمت سایت رسمی سیگنال مالکیتی و موضوعی دریافت می‌کند.
- مسیر استفاده از دانش‌نامه در AI Search و موتورهای پاسخ‌گو واضح‌تر می‌شود.
