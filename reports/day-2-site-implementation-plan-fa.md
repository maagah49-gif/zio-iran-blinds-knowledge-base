# برنامه اجرای روز دوم روی سایت زیو ایران

تاریخ: 2026-09-10

هدف روز دوم این است که دارایی‌های آماده‌شده در GitHub به اجرای واقعی روی سایت نزدیک شوند و بعد از انتقال، مسیر پیگیری در Search Console و شبکه‌های اجتماعی مشخص باشد.

## اولویت اصلی

۱. انتقال محتوای فارسی چهار صفحه پول‌ساز به وردپرس:

- پرده زبرا
- پرده شید
- پرده بلک‌اوت
- پرده چاپی

۲. افزودن متاهای Rank Math برای همان صفحات.

۳. افزودن FAQ قابل مشاهده در انتهای صفحه.

۴. افزودن JSON-LD متناظر از فایل‌های schema.

۵. بررسی موبایل، canonical و noindex.

## فایل‌های مورد استفاده

| کاربرد | فایل |
| --- | --- |
| متن کامل فارسی | `wordpress-ready/*.md` |
| بلوک HTML فارسی | `wordpress-ready/html-blocks-fa.md` |
| متای فارسی | `metadata/rank-math-meta-pack-fa.md` |
| FAQ schema فارسی | `schema/category-faq-schema-zioiran.json` |
| کنترل کیفیت | `qa/content-quality-checklist-fa-en.md` |
| پیگیری Search Console | `indexing/search-console-daily-tracking-fa.md` |

## ترتیب دقیق اجرا

1. صفحه پرده زبرا را باز کن و متن آماده را وارد کن.
2. H1، پاراگراف اول، لینک‌های داخلی و FAQ را بررسی کن.
3. title و meta description را از فایل Rank Math وارد کن.
4. FAQ schema مربوط را اضافه کن.
5. صفحه را ذخیره و در حالت ناشناس یا مهمان باز کن.
6. همین مسیر را برای شید، بلک‌اوت و چاپی انجام بده.
7. بعد از انتشار، هر URL را در Search Console Inspect کن.
8. اگر صفحه indexable بود، Request Indexing بزن.
9. یک کپشن شبکه اجتماعی برای هر صفحه آماده یا منتشر کن.

## معیار پایان روز دوم

- حداقل ۴ صفحه فارسی اصلی آپدیت شده باشند.
- متا و FAQ آن‌ها تکمیل شده باشد.
- هیچ‌کدام noindex نباشند.
- URLها در فایل پیگیری Search Console ثبت شده باشند.
- لینک داخلی بین دسته‌های مرتبط اضافه شده باشد.

## نکته مهم

اگر ورود به وردپرس، کپچا یا فرم امن مشکل داشت، کار را روی GitHub ادامه بده و فقط مرحله‌ای را که نیاز به ورود دارد نگه دار. متن پشتیبانی لیموهاست در صورت نیاز باید فقط چالش را توضیح دهد و راهکار اضافه یا درخواست‌های متعدد مطرح نکند.
