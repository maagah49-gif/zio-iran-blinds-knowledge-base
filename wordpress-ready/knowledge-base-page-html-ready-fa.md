## یادداشت اجرا

- URLهای دسته‌بندی بالا نمونه هستند و باید با آدرس واقعی سایت جایگزین شوند.
- اگر صفحه با Elementor ساخته می‌شود، متن اصلی در Text Editor و اسکیما در Custom Code یا Rank Math Schema قرار گیرد.
- بعد از انتشار، canonical باید روی `https://zioiran.com/knowledge-base/` باشد.
