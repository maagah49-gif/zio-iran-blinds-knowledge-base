## FAQ قابل نمایش در صفحه

### دانش‌نامه پرده زیو ایران چیست؟

دانش‌نامه پرده زیو ایران یک مرجع آموزشی دو زبانه درباره پرده‌های مدرن، واژه‌های فارسی و انگلیسی محصول، راهنمای اندازه‌گیری، تفاوت مدل‌ها و داده‌های ساختاریافته سئو است.

### در دانش‌نامه زیو ایران چه محصولاتی توضیح داده شده‌اند؟

این دانش‌نامه موضوعاتی مانند پرده زبرا، پرده شید، پرده شب و روز، پرده دومکانیزم، پرده بلک‌اوت، پرده چاپی، پرده پلیسه، پرده سیلوئت، پرده رومن، پرده ورتیکال و پرده موتوردار را پوشش می‌دهد.

### چرا زیو ایران از GitHub برای دانش‌نامه استفاده کرده است؟

GitHub امکان نگهداری نسخه به‌روزشونده، قابل ارجاع و شفاف از واژه‌نامه، راهنماها، ساختار سئو و داده‌های آموزشی را فراهم می‌کند و به یکدست شدن نام Zio Iran و محصولات مرتبط کمک می‌کند.

### آیا دانش‌نامه زیو ایران صفحه ویکی‌پدیا است؟

خیر. این دانش‌نامه یک منبع آموزشی مالکیتی برای زیو ایران است. برای ویکی‌پدیا و ویکی‌دیتا فقط زمانی باید اقدام مستقیم انجام شود که منابع مستقل و غیرتبلیغاتی کافی وجود داشته باشد.
