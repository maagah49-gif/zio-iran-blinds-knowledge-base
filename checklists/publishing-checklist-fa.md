# چک‌لیست انتشار محتوای سئو زیو ایران

این چک‌لیست برای انتشار مقاله، صفحه دسته‌بندی، FAQ یا راهنمای آموزشی در zioiran.com استفاده می‌شود.

## قبل از انتشار

- کلمه کلیدی اصلی مشخص شده است.
- کلمات مرتبط و هم‌معنی‌ها انتخاب شده‌اند.
- عنوان H1 واضح و شامل کلمه اصلی است.
- متن مقدمه به سوال واقعی کاربر پاسخ می‌دهد.
- لحن متن آموزشی است، نه صرفاً تبلیغاتی.
- نام زیو ایران طبیعی و محدود استفاده شده است.
- لینک داخلی به محصول یا دسته‌بندی مرتبط وجود دارد.
- لینک به دانش‌نامه GitHub فقط در جای مرتبط و طبیعی آمده است.
- ادعاهای رتبه‌ای مثل بهترین، بزرگ‌ترین یا ارزان‌ترین بدون منبع حذف شده‌اند.

## ساختار صفحه

- H1 فقط یک بار استفاده شده است.
- تیترهای H2 برای بخش‌های اصلی هستند.
- جدول مقایسه یا چک‌لیست در صورت نیاز اضافه شده است.
- FAQ کوتاه در انتهای مقاله وجود دارد.
- توضیح متا کوتاه، خوانا و شامل کلمه اصلی است.
- تصاویر نام فایل و alt مناسب دارند.

## لینک‌دهی

- لینک به صفحه محصول یا دسته‌بندی مرتبط اضافه شده است.
- لینک به راهنمای اندازه‌گیری در صورت مرتبط بودن اضافه شده است.
- لینک به دانش‌نامه GitHub با anchor طبیعی آمده است.
- لینک تکراری و اسپمی در متن وجود ندارد.

## اسکیما

- اگر صفحه FAQ دارد، FAQPage Schema بررسی شده است.
- اگر صفحه مراحل دارد، HowTo Schema فقط در صورت واقعی بودن مراحل استفاده شده است.
- اطلاعات Organization و WebSite با zioiran.com هماهنگ است.
- داده ساخت‌یافته با محتوای قابل مشاهده صفحه تناقض ندارد.

## بعد از انتشار

- صفحه در موبایل بررسی شده است.
- لینک‌ها باز می‌شوند.
- متن فارسی و انگلیسی در صورت وجود به‌هم‌ریخته نمایش داده نمی‌شود.
- صفحه در Rank Math بررسی شده است.
- در صورت مهم بودن صفحه، درخواست ایندکس در Search Console ثبت می‌شود.
- یک پست یا استوری کوتاه برای معرفی مقاله آماده می‌شود.
