# چک‌لیست انتخاب تصویر برای ریلز مشاوره نصب پرده

این چک‌لیست قبل از ساخت یا انتخاب عکس برای ریلز نصب پرده استفاده شود.

## معیارهای ضروری

| معیار | توضیح |
| --- | --- |
| ارتباط مستقیم | تصویر باید دقیقاً همان سؤال را نشان دهد، نه فقط یک پرده زیبا |
| خوانایی | فضای خالی کافی برای متن فارسی داشته باشد |
| سبک برند | ظاهر شیک، لوکس، تمیز و هماهنگ با زیو داشته باشد |
| واقع‌گرایی | مکانیزم پرده واقعی و قابل باور باشد |
| کیفیت | تصویر تار، تیره، شلوغ یا بی‌کیفیت نباشد |
| نسبت تصویر | برای ریلز و استوری 9:16 باشد |

## برای هر شات چه تصویری لازم است؟

| شات | تصویر لازم | اگر عکس واقعی نداریم |
| --- | --- | --- |
| شروع | پنجره لوکس با پرده مدرن | ساخت تصویر با پرامپت شات ۱ |
| سقفی/دیواری | محل نصب روی سقف و دیوار مشخص باشد | ساخت تصویر با فلش‌های ظریف |
| روکار/توکار | مقایسه داخل قاب و بیرون قاب | تصویر دو بخشی ساخته شود |
| پنجره بازشو | پنجره به داخل باز شود و مسیر گیرکردن دیده شود | صحنه واقع‌گرایانه ساخته شود |
| بالا دادن پرده | شخص برای باز کردن پنجره پرده را بالا داده | تصویر با حس دردسر روزمره ساخته شود |
| دستگیره | نمای نزدیک دستگیره و فاصله با پرده | تصویر close-up با خط اندازه‌گیری |
| مکانیزم‌ها | زبرا، شید، بلک‌اوت، برقی | چهار پنل هماهنگ و واقعی |
| پایان | ارسال عکس پنجره برای مشاوره | تصویر گوشی + پنجره + لوگوی زیو |

## چیزهایی که نباید استفاده شود

- عکس پرده نامرتبط با متن شات
- تصویر صرفاً تزئینی بدون مفهوم نصب
- عکس تیره یا خیلی شلوغ
- پرده اشتباه برای مکانیزم معرفی‌شده
- نوشته زیاد روی عکس
- لوگوی خیلی کوچک یا ناخوانا
- ادعای تبلیغاتی مثل بهترین نصب پرده ایران

## پیشنهاد اجرایی

اول چهار تصویر آموزشی اصلی ساخته یا انتخاب شود:

1. سقفی یا دیواری
2. روکار یا توکار
3. گیر کردن پنجره به پرده
4. دستگیره و فاصله پرده

بعد از تأیید این چهار تصویر، بقیه شات‌ها تکمیل شوند. این مسیر باعث می‌شود ریلز آموزشی‌تر و قابل اعتمادتر شود.
