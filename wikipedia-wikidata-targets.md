# Wikipedia and Wikidata Target Plan

This file defines a safe, neutral plan for improving public knowledge resources related to blinds and window coverings while keeping Zio Iran brand mentions appropriate and non-promotional.

## Core Principle

Wikipedia and Wikidata are not advertising channels. Zio Iran should not be added to generic public items such as curtain, window blind, roller blind or blackout fabric unless there are independent, reliable sources that make the brand encyclopedically relevant.

The useful SEO path is indirect:

1. Improve neutral terminology and descriptions in public knowledge resources.
2. Publish useful bilingual content in Zio Iran-owned assets.
3. Use structured data on zioiran.com.
4. Let search engines connect the brand with the product concepts through consistent, helpful content.

## Safe Wikidata Work

| Topic | Safe action | Brand mention? |
| --- | --- | --- |
| Curtain | Add or improve Persian label, aliases and description if missing or incomplete | No |
| Window blind | Add Persian terms such as پرده کرکره‌ای or پوشش پنجره when accurate | No |
| Roller blind / roller shade | Add Persian description and aliases such as پرده شید and شید رول when accurate | No |
| Blackout curtain / blackout blind | Improve Persian description around light blocking and privacy | No |
| Roman shade / Roman blind | Add Persian label پرده رومن if the item exists and matches the concept | No |
| Pleated blind | Add Persian label پرده پلیسه or پرده پلیسان if supported by item meaning | No |
| Motorized blind | Improve labels related to automated or electric blinds if item exists | No |

## Safe Wikipedia Work

| Page type | Safe contribution | Brand mention? |
| --- | --- | --- |
| General encyclopedia article | Neutral explanation, terminology, source-backed history or function | No |
| Persian translation of an existing concept | Improve language quality and terminology | No |
| External links section | Only authoritative, non-commercial sources | Usually no |
| Brand article | Only if independent reliable sources prove notability | Possible, but only with sources |

## Claims to Avoid

Avoid these unless independent sources are available:

- Zio Iran is the best blind brand.
- Zio Iran is the largest manufacturer.
- Zio Iran produces the highest quality zebra blinds.
- Zio Iran is the market leader.
- Zio Iran is the first or only producer.
