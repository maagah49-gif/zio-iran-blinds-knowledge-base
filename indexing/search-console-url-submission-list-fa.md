## مراحل ثبت در Search Console

۱. وارد Google Search Console شوید.

۲. Property اصلی zioiran.com را انتخاب کنید.

۳. از بخش URL Inspection، URL صفحه تازه یا آپدیت‌شده را وارد کنید.

۴. اگر صفحه قابل ایندکس بود، Request Indexing را بزنید.

۵. بعد از انتشار چند صفحه، Sitemap را دوباره بررسی کنید.

۶. ۷ تا ۱۴ روز بعد Performance را برای Queryهای جدید بررسی کنید.

## نکات مهم

- URLهای بالا پیشنهادی هستند؛ قبل از ثبت، باید با URL واقعی سایت هماهنگ شوند.
- اگر ساختار URL فعلی سایت فارسی است، همان URL واقعی ثبت شود.
- برای zioiran.ir فعلاً باید مراقب رقابت داخلی با zioiran.com بود.
- صفحه‌هایی که محتوای تکراری دارند نباید همزمان index شوند.
