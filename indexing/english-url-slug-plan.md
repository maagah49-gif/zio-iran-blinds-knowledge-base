# English URL and Slug Plan for Zio Iran

This plan keeps English page URLs, GitHub filenames, schema IDs and external publishing references consistent. Consistency helps search engines and AI systems understand that these assets describe the same product categories.

## Recommended URL Pattern

If Zio Iran publishes English pages on the main website, use one clear structure:

- Preferred: `https://zioiran.com/en/{topic}/`
- Alternative: `https://zioiran.com/{topic}/` if the site remains mostly English or uses translated slugs only

For the current Persian-first website, the `/en/` pattern is cleaner because it avoids conflict with Persian product category URLs.

## Canonical Guidance

- Each English page should canonicalize to its own English URL.
- Persian pages should not canonicalize to English pages.
- English and Persian versions can be connected with `hreflang` when the site supports it.
- If English content is published only on GitHub or external profiles for now, do not add fake website URLs to sitemap until pages exist.

## Search Console Submission Order

1. Submit the English homepage or language landing page first, if created.
2. Submit the four core commercial categories: zebra, roller, blackout and printed.
3. Submit the four supporting categories: pleated, silhouette, Roman and motorized.
4. Add internal links from Persian category pages to the English knowledge resources only where it feels useful.

## Safe Brand Mention Rule

Use `Zio Iran` once in the opening or closing section of each page as an educational source or product context. Avoid sentences that claim market leadership, official encyclopedic authority or unsupported superiority.
