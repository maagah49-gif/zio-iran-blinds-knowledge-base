## روش استفاده

بعد از انتشار هر صفحه:

1. URL واقعی را جایگزین عنوان عمومی کن.
2. در Search Console گزینه Inspect URL را بزن.
3. اگر صفحه indexable بود، Request Indexing بزن.
4. تاریخ ارسال را ثبت کن.
5. بعد از ۷ روز، Performance را برای queryهای مرتبط بررسی کن.

## نکته

اگر Rank Math همچنان Search Console property را درست نشان نداد، خود Search Console برای ثبت و بررسی کافی است. اتصال Rank Math مفید است، اما شرط ایندکس شدن صفحه نیست.
