## روش بررسی

1. بعد از لینک دادن از `zioiran.com` به repository، ابتدا URL صفحه سایت را در Search Console inspect کنید.
2. سپس URL اصلی repository را در گوگل با جستجوی `site:github.com/maagah49-gif/zio-iran-blinds-knowledge-base Zio Iran` بررسی کنید.
3. اگر صفحه ایندکس نشده بود، از لینک داخلی سایت و پروفایل‌های بیرونی برای تقویت discovery استفاده کنید.
4. وضعیت هر URL را در فایل tracking روزانه ثبت کنید.

## نکته

GitHub الزاماً از Search Console سایت زیو قابل submit مستقیم نیست، چون روی دامنه github.com قرار دارد. اما لینک دادن از سایت رسمی، پروفایل‌های بیرونی و صفحات ایندکس‌شده می‌تواند discovery آن را تقویت کند.
