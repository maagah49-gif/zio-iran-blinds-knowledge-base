# صف ثبت URLهای Discovery

این فایل برای ثبت دستی URLهای جدید GitHub Pages در ابزارهای ایندکس و کنترل پس از انتشار است.

| اولویت | URL | کاربرد |
|---|---|---|
| 1 | https://maagah49-gif.github.io/zio-iran-blinds-knowledge-base/ | صفحه اصلی دانش‌نامه |
| 2 | https://maagah49-gif.github.io/zio-iran-blinds-knowledge-base/supplemental-assets.html | صفحه عمومی دارایی‌های مکمل |
| 3 | https://maagah49-gif.github.io/zio-iran-blinds-knowledge-base/discovery.json | فایل کشف‌پذیری برای AI و mapping |
| 4 | https://maagah49-gif.github.io/zio-iran-blinds-knowledge-base/feed.json | فید JSON برای تغییرات مهم |
| 5 | https://maagah49-gif.github.io/zio-iran-blinds-knowledge-base/urls.txt | لیست ساده URLها |
| 6 | https://maagah49-gif.github.io/zio-iran-blinds-knowledge-base/sitemap.xml | sitemap اصلی |

## روند اجرا

1. پس از refresh شدن GitHub Pages، URLهای اول تا پنجم را با URL Inspection در Google Search Console بررسی کن.
2. sitemap اصلی را در بخش Sitemaps ثبت یا دوباره submit کن.
3. برای هر URL وضعیت crawl، indexability و canonical را در گزارش روزانه ثبت کن.
4. اگر صفحه‌ای fetch نشد، ابتدا GitHub Pages build و سپس robots/sitemap را بررسی کن.
