# Pleated Blinds

Pleated blinds are fabric window coverings made with crisp folds. When raised, the fabric stacks neatly, making this type useful for compact windows, doors and spaces where a slim profile is preferred.

In Zio Iran content, pleated blinds should be connected with the Persian terms "پرده پلیسان" and "پرده پشت دری" when the product is used for door-mounted applications.

## Common Uses

- Door windows
- Kitchen windows
- Compact residential openings
- Spaces that need a tidy, lightweight blind
