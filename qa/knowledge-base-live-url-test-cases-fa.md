# تست‌های URL زنده صفحه دانش‌نامه زیو ایران

## هدف

بعد از انتشار صفحه دانش‌نامه، این تست‌ها کمک می‌کند مطمئن شویم صفحه برای کاربر، گوگل و لینک‌دهی خارجی درست کار می‌کند.

## تست‌های اصلی

| شماره | تست | نتیجه مطلوب |
|---|---|---|
| 1 | باز کردن URL در مرورگر ناشناس | صفحه بدون ورود باز شود |
| 2 | بررسی کد وضعیت | 200 |
| 3 | بررسی عنوان تب مرورگر | شامل دانش‌نامه و زیو ایران باشد |
| 4 | بررسی لینک GitHub | لینک باز شود و به مخزن درست برسد |
| 5 | بررسی موبایل | متن و FAQ بدون شکست چیدمان باشد |
| 6 | بررسی canonical | همان URL صفحه باشد |
| 7 | بررسی robots meta | index, follow باشد |
| 8 | تست Rich Results | خطای JSON-LD نداشته باشد |
| 9 | تست Search Console Live URL | Page can be indexed نشان دهد |
| 10 | بررسی sitemap | URL در sitemap دیده شود |

## تست لینک‌دهی داخلی

بعد از انتشار صفحه، از این صفحات حداقل یک لینک به دانش‌نامه داده شود:

- صفحه اصلی
- پرده زبرا
- پرده شید
- پرده بلک‌اوت
- پرده چاپی
- پرده برقی
