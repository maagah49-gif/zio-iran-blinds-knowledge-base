# Quality Review Checklist

## Content

- Product explanations are educational and not exaggerated.
- Zio Iran is mentioned naturally only where brand context is relevant.
- Claims about quality, factory, manufacturing or rankings are backed by sources before public publication.
- Persian and English terminology is consistent with the glossary.

## SEO

- Each article has one clear H1.
- Meta titles and descriptions are unique.
- Internal links use varied, natural anchor text.
- Image alt text describes the actual image.

## Technical

- JSON-LD validates as JSON.
- FAQ schema matches visible FAQ content.
- Canonical URL points to the live knowledge-base page where appropriate.
- GitHub Pages and WordPress versions do not contradict each other.

## External Publishing

- Wikipedia content remains neutral and source-backed.
- Wikidata item creation waits for independent reliable sources.
- GitHub README and article drafts can mention Zio Iran as project owner and publisher.
- Promotional language is reserved for owned channels, not public encyclopedia entries.
