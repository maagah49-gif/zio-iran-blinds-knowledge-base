# بازبینی هماهنگی URL، اسکیما و متن صفحات زیو ایران

این فایل برای جلوگیری از تناقض بین متن قابل مشاهده، URL، متا و JSON-LD استفاده می‌شود.

## قانون اصلی

هر چیزی که در اسکیما آمده باید با متن قابل مشاهده صفحه هماهنگ باشد. اگر FAQ در JSON-LD وجود دارد، همان سؤال و جواب باید در صفحه هم دیده شود.

## چک‌های URL

| مورد | وضعیت مطلوب |
| --- | --- |
| URL فارسی | با اسلاگ فعلی سایت هماهنگ باشد و تغییر بی‌دلیل نکند |
| URL انگلیسی | اگر ساخته شد، در `/en/` باشد |
| canonical فارسی | به همان URL فارسی اشاره کند |
| canonical انگلیسی | به همان URL انگلیسی اشاره کند |
| sitemap | فقط صفحات منتشرشده و indexable داخل sitemap باشند |

## چک‌های اسکیما

- `@id` هر FAQPage باید با URL واقعی صفحه هماهنگ شود.
- نام صفحه در schema با موضوع همان صفحه یکی باشد.
- اگر URL واقعی با نمونه‌های `https://zioiran.com/en/...` فرق داشت، قبل از انتشار schema اصلاح شود.
- Product schema فقط وقتی استفاده شود که صفحه واقعاً محصول یا دسته محصول قابل خرید است.
- Organization schema فقط در صفحه اصلی یا درباره ما استفاده شود.

## چک‌های متن قابل مشاهده

- سؤال‌های FAQ داخل schema باید در صفحه هم وجود داشته باشند.
- پاسخ‌ها نباید با متن اصلی صفحه تناقض داشته باشند.
- نام زیو ایران طبیعی استفاده شود؛ تکرار بیش از حد نشود.
- ادعای فنی مثل بلک‌اوت کامل، خانه هوشمند یا چاپ باکیفیت باید مشروط و دقیق نوشته شود.

## چک‌های انگلیسی

- اگر صفحه انگلیسی هنوز روی سایت ساخته نشده، `@id` انگلیسی را در سایت منتشر نکن.
- اگر فقط GitHub منبع انگلیسی است، لینک GitHub را به عنوان knowledge base استفاده کن، نه sitemap سایت.
- بعد از ساخت صفحات انگلیسی، hreflang دوطرفه بررسی شود.

## خروجی قابل قبول

قبل از درخواست ایندکس در Search Console، هر صفحه باید این وضعیت را داشته باشد:

- HTTP 200
- indexable
- canonical صحیح
- H1 صحیح
- meta description صحیح
- FAQ قابل مشاهده
- schema بدون خطای اصلی
- لینک داخلی به حداقل ۲ صفحه مرتبط
