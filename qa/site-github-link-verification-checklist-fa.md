# چک‌لیست کنترل لینک سایت زیو ایران به GitHub Knowledge Base

این چک‌لیست بعد از اضافه شدن لینک دانش‌نامه GitHub در سایت `zioiran.com` استفاده می‌شود.

## کنترل فنی لینک

| مورد | وضعیت مطلوب |
|---|---|
| لینک GitHub قابل کلیک است | بله |
| لینک در صفحه قابل ایندکس قرار دارد | بله |
| لینک در متن توضیحی آمده، نه فقط فوتر | بله |
| `target="_blank"` برای خروج از سایت تنظیم شده | بله |
| `rel="noopener"` وجود دارد | بله |
| URL دقیق repository استفاده شده | بله |
| Anchor text طبیعی و مرتبط است | بله |

## کنترل محتوایی

| سوال | پاسخ مطلوب |
|---|---|
| آیا متن لینک برای کاربر مفید است؟ | بله |
| آیا نام زیو ایران طبیعی آمده؟ | بله |
| آیا متن بیش از حد تبلیغاتی نیست؟ | بله |
| آیا کلمات پرده زبرا، شید، بلک‌اوت یا دانش‌نامه پرده در اطراف لینک آمده‌اند؟ | بله |
| آیا لینک با موضوع صفحه هماهنگ است؟ | بله |

## Anchor Textهای مجاز

- دانش‌نامه پرده‌های مدرن زیو ایران
- دانش‌نامه دو زبانه پرده زیو ایران
- واژه‌نامه فارسی و انگلیسی پرده
- Zio Iran Blinds Knowledge Base
- bilingual blinds knowledge base

## Anchor Textهایی که بهتر است استفاده نشود

- بهترین مرجع پرده ایران
- خرید پرده ارزان
- بهترین پرده زبرا
- لینک بک‌لینک زیو

## تست بعد از انتشار

1. صفحه را در مرورگر ناشناس باز کنید.
2. روی لینک GitHub کلیک کنید.
3. مطمئن شوید صفحه GitHub باز می‌شود.
4. سورس صفحه را بررسی کنید و ببینید لینک در HTML وجود دارد.
5. URL صفحه سایت را در Search Console inspect کنید.
6. بعد از چند روز، جستجوی `Zio Iran Blinds Knowledge Base` و `زیو ایران دانش‌نامه پرده` را بررسی کنید.

## نتیجه مطلوب

لینک باید هم برای کاربر معنی داشته باشد، هم برای موتور جستجو نشان دهد که دانش‌نامه GitHub یک دارایی رسمی و آموزشی مرتبط با زیو ایران است.
