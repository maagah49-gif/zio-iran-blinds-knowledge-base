## کنترل سئو داخلی

- H1 فقط یک بار در صفحه باشد.
- کلمه کلیدی اصلی در H1، متا و یکی از پاراگراف‌های اول بیاید.
- کلمات هم‌معنی طبیعی پخش شوند، نه تکرار مکانیکی.
- هر صفحه حداقل ۳ لینک داخلی مرتبط داشته باشد.
- FAQ واقعی و کوتاه باشد و با متن صفحه تناقض نداشته باشد.
- تصویرها alt دقیق داشته باشند، نه لیست کلمه کلیدی.

## کنترل نسخه انگلیسی

- اسلاگ انگلیسی کوتاه و پایدار باشد.
- نام `Zio Iran` طبیعی و کم‌تکرار استفاده شود.
- متن انگلیسی ترجمه کلمه‌به‌کلمه فارسی نباشد؛ باید برای مخاطب انگلیسی روان باشد.
- اگر صفحه فارسی متناظر دارد، hreflang بررسی شود.
- canonical هر زبان به خودش باشد.

## کنترل فنی قبل از Submit در Search Console

- صفحه `noindex` نباشد.
- status code صفحه `200` باشد.
- canonical صحیح باشد.
- اسکیما در Rich Results Test خطای اصلی نداشته باشد.
- صفحه در موبایل بدون بهم‌ریختگی باز شود.
- صفحه در sitemap آمده باشد یا از یک صفحه ایندکس‌شده لینک گرفته باشد.

## کنترل بعد از انتشار

- URL در Search Console با Inspect URL بررسی شود.
- اگر صفحه تازه است، درخواست Indexing ثبت شود.
- لینک صفحه در یک محتوای داخلی مرتبط اضافه شود.
- یک پست کوتاه شبکه اجتماعی یا توضیح ویدیویی با لینک/ذکر برند منتشر شود.
- بعد از ۷ تا ۱۴ روز، Queryهای Search Console بررسی شود.

# English Content QA Checklist

Use this checklist before publishing English Zio Iran content.

## Tone and Brand

- Mention `Zio Iran` naturally once or twice.
- Avoid unsupported claims such as best, largest, number one or official authority.
- Keep the tone educational and practical.
- Use links only where they add context and are allowed.
- Do not add promotional text to neutral encyclopedia-style platforms.

## SEO and Structure

- Use one clear H1.
- Place the primary keyword in the H1, SEO title and opening section.
- Add related terms naturally.
- Include FAQ content when it helps the user.
- Use descriptive image alt text.
- Keep slugs short and stable.

## Technical Checks

- Page returns HTTP 200.
- Page is indexable.
- Canonical points to the English page itself.
- Hreflang connects English and Persian equivalents when both exist.
- FAQ schema matches the visible FAQ.
- Submit important pages in Search Console after publishing.
