# Wikimedia Commons Category Targets for Blind and Shade Media

This file lists neutral Wikimedia Commons category targets that may be useful for educational media research around blinds and window coverings.

## Safe Use Rules

- Upload only images that Zio Iran owns or that are clearly compatible with Commons licensing.
- Do not upload customer-site photos without written permission.
- Do not use Commons captions as advertising copy.
- Brand names should appear only when the file actually documents that brand and the licensing/source context is clean.
