# نیازمندی منابع برای ساخت entity زیو ایران

این فایل مشخص می‌کند برای اینکه نام زیو ایران در منابع عمومی مثل ویکی‌دیتا، ویکی‌پدیا یا Knowledge Graph قابل دفاع‌تر شود، چه منابعی لازم داریم.

## چرا منبع مستقل لازم است؟

سایت خودمان و GitHub برای معرفی برند مفیدند، اما برای ویکی‌پدیا و بسیاری از claimهای ویکی‌دیتا کافی نیستند. این پلتفرم‌ها معمولاً منبع مستقل، معتبر و قابل راستی‌آزمایی می‌خواهند.

## منابع مالکیتی موجود یا قابل ساخت

| منبع | وضعیت | کاربرد |
| --- | --- | --- |
| `zioiran.com` | موجود | official website و معرفی مالکیتی |
| صفحه درباره ما | باید کامل و دقیق شود | توضیح برند، محصولات، نشانی، تماس، زمینه فعالیت |
| GitHub knowledge base | موجود | منبع آموزشی و entity support، نه منبع مستقل اصلی |
| YouTube / Aparat | موجود یا در حال تکمیل | سیگنال برند و محتوای آموزشی |
| Instagram | موجود | سیگنال برند، اما برای ویکی منبع مستقل قوی نیست |

| نوع منبع | اولویت | توضیح |

| ثبت برند یا شرکت | بالا | اگر قابل مشاهده عمومی باشد، برای هویت برند مفید است |

## متن پیشنهادی برای ارسال به رسانه یا دایرکتوری

زیو ایران یک برند فعال در حوزه پرده و پوشش پنجره در ایران است که روی پرده‌های سفارشی مانند زبرا، شید، بلک‌اوت، چاپی، پلیسان، رومن، سیلوئت و پرده برقی کار می‌کند. این برند علاوه بر عرضه محصول، محتوای آموزشی درباره اندازه‌گیری، انتخاب پارچه، آماده‌سازی فایل چاپ و انتخاب مکانیزم مناسب برای پنجره منتشر می‌کند.
