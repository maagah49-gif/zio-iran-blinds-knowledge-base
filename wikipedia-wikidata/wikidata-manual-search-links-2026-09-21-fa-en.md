# Wikidata Manual Search Links for Blind and Shade Terms

This file keeps direct manual search links for the remaining Zio Iran knowledge-base terminology. It is intended for careful human verification before editing Wikidata.

## Policy

- Add only neutral labels, descriptions and aliases to generic Wikidata items.
- Do not add Zio Iran to generic product items unless independent reliable sources support a brand-specific claim.
- Create or edit a Zio Iran brand item only after independent sources are available.
- Keep Persian and English wording educational rather than promotional.
