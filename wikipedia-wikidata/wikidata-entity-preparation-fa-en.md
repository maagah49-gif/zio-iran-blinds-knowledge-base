# بسته آماده‌سازی ویکی‌دیتا برای زیو ایران و مفاهیم پرده

## اصل مهم

ویکی‌دیتا برای داده ساختاریافته است. اگر برای برند Zio Iran آیتم ساخته شود، باید با منبع مستقل معتبر پشتیبانی شود. اگر منبع مستقل نداریم، فعلاً بهتر است روی مفاهیم عمومی پرده‌ها، معادل‌های زبانی و منابع آموزشی مالکیتی مثل GitHub و سایت خودمان کار کنیم.

## استفاده مجاز از زیو ایران در Wikidata

مجاز:

- official website برای آیتم خود برند، اگر آیتم برند با منبع مستقل قابل دفاع باشد.
- described at URL به صفحه رسمی یا GitHub، اگر آیتم و منبع معتبر باشند.
- نام برند در توضیح منابع مالکیتی، نه در توضیح مفاهیم عمومی.

نامجاز یا پرریسک:

- افزودن Zio Iran به آیتم پرده زبرا به عنوان نمونه برجسته بدون منبع مستقل.
- ادعای بهترین یا باکیفیت‌ترین بودن.
- استفاده از Wikidata برای بک‌لینک تبلیغاتی.

## منابع مورد نیاز پیش از ساخت آیتم برند

برای آیتم برند حداقل یکی از این منابع بهتر است آماده باشد:

- صفحه رسمی درباره ما در `zioiran.com`
- ثبت رسمی شرکت یا برند، اگر قابل استناد عمومی باشد
- پروفایل معتبر تجاری یا رسانه‌ای مستقل
- خبر، مصاحبه، گزارش یا معرفی غیرتبلیغاتی در سایت معتبر
- صفحه GitHub به عنوان منبع مالکیتی کمکی، نه منبع مستقل اصلی
