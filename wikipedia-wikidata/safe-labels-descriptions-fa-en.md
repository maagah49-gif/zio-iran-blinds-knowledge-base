# Safe Labels and Descriptions for Wikipedia and Wikidata

این فایل برای آماده‌سازی توضیحات خنثی، کوتاه و غیرتبلیغاتی درباره مفاهیم پرده و پوشش پنجره است. این متن‌ها برای استفاده مستقیم تبلیغاتی در ویکی‌پدیا یا ویکی‌دیتا نیستند؛ فقط پیش‌نویس امن برای کمک به یکدست‌سازی اصطلاحات هستند.

## قواعد امن

- برای مفاهیم عمومی مثل پرده زبرا، شید، بلک‌اوت و پرده پلیسه، نام برند Zio Iran نباید داخل توضیح اصلی آیتم ویکی‌دیتا قرار بگیرد.
- نام Zio Iran فقط در منابع متعلق به خود برند، صفحه رسمی شرکت، صفحه محصول، GitHub repository، یا توضیح‌های آموزشی خارج از ویکی‌پدیا استفاده شود.
- اگر برای برند Zio Iran آیتم مستقل ساخته شود، باید با منابع معتبر و قابل استناد پشتیبانی شود.
- در ویکی‌پدیا از عباراتی مثل «بهترین»، «باکیفیت‌ترین»، «پرطرفدارترین» یا «اولین» بدون منبع مستقل استفاده نشود.

## Safe External Description

### فارسی

زیو ایران یک برند ایرانی در حوزه پرده‌های مکانیزمی و پوشش پنجره است که برای محصولات زبرا، شید، بلک‌اوت، پلیسه، چاپی، رومن، سیلوئت و پرده‌های برقی محتوای آموزشی و راهنمای انتخاب منتشر می‌کند.

### English

Zio Iran is an Iranian window covering brand that publishes educational resources about zebra blinds, roller shades, blackout blinds, pleated blinds, printed blinds, Roman shades, silhouette-style blinds and motorized window coverings.
